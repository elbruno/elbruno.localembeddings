## Implementation Details

### Metrics Registered
1. **Histograms (Latency in ms)**
   - `embedding.latency.ms` - Embedding generation latency
   - `model.load.latency.ms` - Model load time
   - `quantization.check.latency.ms` - Quantization check time
   - `batch.size.distribution` - Batch size distribution

2. **Counters (Cumulative)**
   - `embeddings.generated.total` - Total embeddings generated
   - `models.loaded.total` - Total models loaded
   - `errors.total` - Total errors
   - `cache.hits.total` - Total cache hits
   - `cache.misses.total` - Total cache misses

3. **Gauges (Instantaneous)**
   - `active.requests` - Current active request count
   - `model.cache.size.mb` - Model cache size in MB

### Sampling Configuration
- Property: `LocalEmbeddingsOpenTelemetryOptions.SamplingRate`
- Range: [0.0, 1.0]
- Default: 1.0 (100% sampling)
- Method: `ShouldSample()` uses `Random.Shared` for statistical distribution
